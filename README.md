# Projeto Artemis

> Quem não tem voz, tem a Artemis.

Plataforma que conecta ONGs, casas de adoção e cidadãos para proteger os animais.
Proteção animal, adoção responsável e denúncias com segurança de dados.

## Áreas

| Área pública (qualquer pessoa) | Área restrita (só ONGs aprovadas) |
| --- | --- |
| Denuncia sem criar conta | Atende denúncias |
| Envia provas | Analisa adotantes |
| Acompanha o caso pelo protocolo | Tudo registrado em auditoria |

## O que tem neste repositório

Tela pública **Denunciar sem medo**: o cidadão conta o que viu e recebe
um protocolo no formato `ART-XXXXX` para acompanhar o caso.

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

## Tecnologias

HTML, CSS e JavaScript.

## Valores

Proteção · Cuidado · Verdade · Segurança (LGPD)
